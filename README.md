# 👤 GitHub Kullanıcı Kartı

Bu proje, **HTML, CSS ve JavaScript** kullanılarak geliştirilmiş basit bir GitHub kullanıcı kartı uygulamasıdır. Girilen GitHub kullanıcı adına göre **GitHub API** üzerinden veriler çekilir ve kullanıcının profil bilgileri kart şeklinde ekranda gösterilir.

## 🚀 Özellikler

- GitHub kullanıcı adına göre arama
- GitHub API ile gerçek zamanlı veri çekme
- Profil bilgilerini kart halinde görüntüleme
- Responsive (mobil uyumlu) tasarım
- Basit ve kullanıcı dostu arayüz

## 🛠️ Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript (ES6)
- GitHub API

## ⚙️ Kurulum

1. Bu repoyu bilgisayarınıza klonlayın.
2. Proje klasörünü açın.
3. `index.html` dosyasını tarayıcıda çalıştırın.

## 📂 Proje Yapısı

```text
├── index.html
├── style.css
├── script.js
└── githubcard.mp4
```

## 📌 Projenin Çalışma Mantığı

1. Kullanıcı GitHub kullanıcı adını girer.
2. JavaScript, GitHub API'ye istek gönderir.
3. API'den dönen kullanıcı bilgileri alınır.
4. Profil fotoğrafı, isim, kullanıcı adı ve diğer bilgiler kart olarak ekranda gösterilir.
